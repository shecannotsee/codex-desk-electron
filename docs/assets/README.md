# 文档素材

截图由独立文档截图窗口生成：

```bash
cd src
npm run capture:docs
```

当前素材：

- `screenshot-main.png`：主界面。
- `screenshot-settings-menu.png`：快捷设置一级菜单。
- `screenshot-settings-nested.png`：快捷设置二级页。
- `screenshot-runtime-tabs.png`：运行面板。
- `screenshot-conversation-context-menu.png`：会话右键菜单。
- `screenshot-chat-copy-menu.png`：选区复制菜单。
- `workflow-step-1-input.png`：输入阶段。
- `workflow-step-2-runtime.png`：运行中。
- `workflow-step-3-result.png`：完成结果。

维护规则：

- 更新 UI 文档前先重新生成截图。
- 不手动裁剪单张截图，保持自动化输出一致。
- 截图窗口独立于日常使用的客户端窗口。
