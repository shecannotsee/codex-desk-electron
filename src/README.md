# Source Directory

This directory contains the Electron source code, TypeScript build config, and Node package files.

- `main/`: TypeScript main-process source
  - `main/app_controller/`: AppController split modules
- `renderer/`: renderer source
  - `renderer/app/`: renderer TypeScript modules
  - `renderer/styles.css`: theme and layout styles
- `app/`: compiled runtime output generated by `npm run build`
- `package.json`: scripts and dependencies
- `tsconfig.main.json`: main/scripts compilation config
- `tsconfig.renderer.json`: renderer compilation config
- `electron-builder.yml`: Ubuntu DEB packaging config
- `scripts/postbuild-copy.ts`: copies static assets into `app/`
- `scripts/sync-logo.ts`: prepares the application icon from `../resource/logo.png`
